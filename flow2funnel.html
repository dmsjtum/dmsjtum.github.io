Flow2Funnel: Feedback-Complete Action Heads for Vision–Language–Action Policies

Learning local feedback for the time between VLA replans.让学习到的局部反馈，补上 VLA 两次重规划之间的执行环节。

Miaomiao Dai · Personal research proposal · 2026个人研究构想 · 2026

Research question核心研究问题

At the same VLA planning budget, can local feedback improve disturbance recovery—and identify when a new plan is needed?在相同的 VLA 规划预算下，局部反馈能否提高扰动恢复能力，并判断何时需要新的计划？

Training data and predictions训练数据与预测

Pair nominal and perturbed executions of the same sampled plan. Measured state offsets and action changes provide the supervision:对同一采样计划进行名义执行和扰动执行，以测得的状态偏差与动作变化作为监督：

dk = zkpert − zknom
δak = akpert − āk
d̂k+1(θ) = Ak(θ)dk + Bk(θ)δak

A propagates state offsets; B maps action changes to the next offset. The head also predicts reference states z̄ and uncertainty Σ. Measured transitions provide targets without direct matrix labels.A 传播已有状态偏差，B 描述动作变化的影响；头同时预测参考状态 z̄ 和不确定性 Σ。监督来自实测转移，无需直接提供矩阵标签。图中的 d⁺ 表示下一步实测状态偏差，δa 表示相对名义动作施加的扰动。

In the figure, d⁺ is the next measured state deviation; δa is the applied probe-action change relative to the nominal action.

Head parameterization头的参数化

The plan, cached context and initial state condition the head. In normalized coordinates:头以计划、缓存上下文和起始状态为条件。在归一化坐标中：

Ak = I + Δt [diag(Dk) + UkVkT]
Bk = Δt B̃k
Σk = diag(softplus(sk) + 10−6)

The current reference head predicts displacement from the initial state: z̄k = z₀ + Δk. Training deviation d uses measured nominal states; execution error e = z − z̄ uses the predicted reference.当前参考头预测相对起始状态的位移：z̄k = z₀ + Δk。训练偏差 d 基于实测名义状态，执行误差 e = z − z̄ 则基于预测参考。

The objective optimized during training实际参与梯度优化的总损失

Ltrain(θ) = Lref(θ) + Ldyn(θ)

Reference fit: predict the recorded nominal trajectory.参考拟合：预测记录下来的名义轨迹。

Lref(θ) = (1/Ncalls) ∑nom ‖z̄k(θ) − sg(zknom)‖²

Dynamics fit: predict the measured next-state response and its uncertainty.动力学拟合：预测实测的下一步响应及其不确定性。

rk(θ) = dk+1 − Ak(θ)dk − Bk(θ)δak
Ldyn(θ) = (1/Ncalls) ∑probe[rkTΣk−1rk + log det Σk]

Gradient updates: Adam updates θ—the feedback queries and output heads, including the z₀ projection. The policy and measured targets stay fixed; training does not backpropagate through Riccati.梯度更新：Adam 更新 θ，即反馈 queries 与输出 heads（包括 z₀ 投影）。基础策略与测量目标固定，训练不经过 Riccati 反向传播。

Loss conventions and optimizer损失约定与优化器

Both loss weights equal 1. The nominal sum runs over valid recorded states and the probe sum over valid paired transitions, across all sampled-plan calls; both are divided by Ncalls. In the dynamics expression, r and Σ depend on θ. sg means stop-gradient.两项损失权重均为 1。nom 对全部计划调用中的有效名义状态求和，probe 对有效成对转移求和，再分别除以调用数 Ncalls。动力学式中的 r、Σ 均依赖 θ；sg 表示停止梯度。

The current optimizer is AdamW with zero weight decay and global gradient-norm clipping at 1. The Gaussian term uses the displayed convention without a 1/2 multiplier. Riccati uses a separate fixed quadratic control objective during compilation.当前优化器为权重衰减为零的 AdamW，全局梯度范数裁剪阈值为 1。高斯项按所示公式计算，不乘 1/2。Riccati 在编译阶段使用独立的固定二次控制目标。

Why this question为什么研究这个问题

VLA policies turn visual and language context into useful action sequences. When inference takes time, however, a robot may continue executing an earlier chunk while the scene changes. More frequent replanning is one response; a complementary possibility is to use inexpensive, task-relevant feedback between updates.

VLA 策略能把视觉与语言信息转化为动作序列。但推理需要时间，场景发生变化时，机器人可能仍在执行上一段计划。提高重规划频率是一种应对方式；另一条互补路径，是在两次更新之间加入低成本、与任务相关的反馈。

Working hypothesis. For disturbances with enough remaining action authority and observable state, feedback around the sampled plan may improve recovery during long execution windows without degrading nominal performance. The study must count sensing and control latency, not only VLA calls.

待检验假设。对于仍有足够动作余量、且状态可观测的扰动，围绕采样计划的反馈可能改善长执行窗口内的恢复，同时保持无扰动任务表现。评估需要计入感知与控制时延，不能只统计 VLA 调用次数。

One action chunk, a feedback loop between replans围绕一个动作块，在重规划之间持续反馈

  1. Sample a plan. The frozen VLA uses images, an instruction and proprioception to sample a nominal action chunk ā. This gives the robot a planned sequence to execute; the sampled plan and cached context also become inputs to the feedback head.采样计划。冻结 VLA 根据图像、指令和本体感知，采样名义动作块 ā，给出待执行的动作序列。采样计划与缓存的上下文同时作为反馈头的输入。
  2. Attach local feedback. After sampling, feedback queries read the plan and cached context. These features and initial state z₀ condition a local head that predicts reference states z̄ and dynamics A/B. Riccati converts those dynamics and fixed costs into feedback gains K and quadratic weights P.生成局部反馈。采样完成后，反馈查询读取计划和缓存上下文；所得特征与起始状态 z₀ 一起输入局部头，预测参考状态 z̄ 和动力学 A/B。Riccati 再根据动力学与固定代价，计算反馈增益 K 和二次型权重 P。
  3. Correct during execution. At each step, compare fresh state zₖ with reference z̄ₖ to obtain error eₖ. Add a bounded correction −Kₖeₖ, or zero when correction is disabled, to nominal action āₖ. A separate handoff decision can request a new plan.校正执行。每一步比较最新状态 zₖ 和参考 z̄ₖ，得到误差 eₖ，再将受限幅约束的校正量 −Kₖeₖ 加到名义动作 āₖ 上；校正关闭时加零。另一个独立的交接判断可以请求新计划。
Technical details, training and current limits技术细节、训练与当前边界

Compilation. The local head also predicts uncertainty Σ. Reference states come directly from the head; Riccati uses A/B and fixed running and terminal costs to compute K/P. Uncertainty supports terminal prediction and does not enter Riccati. Controller and handoff terms are cached with the plan.控制器编译。局部头还预测不确定性 Σ。参考状态由头直接输出；Riccati 用 A/B 及固定的运行代价和终端代价计算 K/P。不确定性用于终端预测，不进入 Riccati。控制器与交接评估参数随计划一起缓存。

Correction gate. With eₖ = zₖ − z̄ₖ and V = eᵀPe, correction requires a defined action-limit certificate and V ≤ ρ_act. The current radius reflects nominal action headroom. A closed gate leaves the nominal action in place; current LIBERO feedback changes six arm-action dimensions and keeps the gripper nominal.校正门。定义 eₖ = zₖ − z̄ₖ、V = eᵀPe。只有动作限幅证书有效且 V ≤ ρ_act 时才启用校正；当前半径反映名义动作的剩余余量。门关闭时保持名义动作。当前 LIBERO 反馈仅校正六维机械臂动作，夹爪动作保持名义值。

Separate handoff. Dynamics A/B, gains K, task-coordinate map C and horizon H define a terminal-error map M; Σ supplies propagated uncertainty σ_H. The test ‖Mₖeₖ‖ + κσ_H[k] > ε_task can request a new chunk, subject to the planning budget and scheduler. The handoff horizon may be shorter than the sampled chunk. Closing the correction gate alone does not trigger replanning.独立交接。动力学 A/B、增益 K、任务坐标映射 C 和时域 H 共同确定终端误差映射 M；Σ 提供传播后的不确定性 σ_H。当 ‖Mₖeₖ‖ + κσ_H[k] > ε_task 时，可在规划预算与调度规则允许的条件下请求新动作块。交接时域可能短于采样动作块，校正门关闭本身不触发重规划。

Training. Nominal and perturbed transitions supervise feedback queries and local output heads. The VLA remains frozen; current training does not backpropagate through Riccati. The dynamics head learns physical responses rather than derivatives of the policy or flow sampler.训练。名义与扰动转移数据监督反馈查询和局部输出头。VLA 保持冻结，当前训练不经过 Riccati 反向传播。动力学头学习物理响应，而非策略或流采样器的导数。

Current limits. The proposed recovery region remains conceptual. A validated model-error bound and deployment-compatible state estimation remain research targets. Reported feedback evaluations use simulator state; these checks do not guarantee semantic task success or real-world safety. Coordinate whitening and actuator-specific details are omitted from the figure.当前边界。所提出的恢复区域仍处于概念阶段。经验证的模型误差界与部署可用的状态估计仍是研究目标。目前反馈评估使用仿真器状态，这些检查不保证语义任务成功或真实系统安全。图中省略了坐标白化与执行器细节。

What the evidence supports so far目前证据支持到哪一步

Controlled contact simulation受控接触仿真

A held-out planar-push evaluation supports the combined feedback-and-handoff system. It is a simplified setting with state access and additional planning calls, so it does not establish a gain at matched planning cost.封存的平面推物评估支持反馈与交接组合系统的有效性。但这仍是状态可得的简化环境，且包含额外规划调用，尚不能据此主张相同规划代价下的收益。

Frozen π0.5 in LIBERO冻结 π0.5 的 LIBERO 集成

Integration is complete, but the held-out disturbance test did not detect a recovery improvement. Nominal performance met its preset non-inferiority criterion. These results motivate testing when feedback can meaningfully intervene.已完成集成，但封存扰动测试尚未检出恢复收益；无扰动表现通过预设非劣判据。后续需要检验反馈在哪些条件下能真正介入并发挥作用。

Main open question: can deployment-available visual state estimates support a useful local recovery region? Current feedback evaluations use simulator state; Flow2Funnel has no verified real-robot benefit yet.关键未解问题：部署可得的视觉状态估计，能否支撑足够有效的局部恢复区域？目前反馈评估使用仿真器状态，Flow2Funnel 尚无已验证的真机收益。

An initial RA study可开展的 RA 研究计划

A proposed 8–10 week study, scoped with a host lab:以下是可与合作实验室共同细化的 8–10 周初步计划：

  1. Measure the opportunity. Fix one policy and a small manipulation task set. Measure inference delay, disturbance recovery, action authority, and state-estimation error. Define the evaluation conditions before testing.确认反馈的作用空间。固定一个策略和一组小规模操作任务，测量推理延迟、扰动恢复、动作余量与状态估计误差，并在测试前明确评估条件。
  2. Test the learned model. Compare Riccati feedback with a direct residual controller and a known-model reference. Separate model fidelity from actual recovery, and analyze how model error affects the correction region.检验学到的模型。将 Riccati 反馈与直接残差控制器、已知模型参考作比较，区分预测准确性与实际恢复能力，分析模型误差如何影响校正区域。
  3. Establish runtime value. Match VLA calls against periodic and asynchronous replanning, including RTC. Report success, calls, and total latency; ablate correction and handoff separately. Attempt a small hardware pilot only after simulation and observation checks pass.验证运行时价值。与周期重规划及 RTC 等异步方案匹配 VLA 调用预算，报告成功率、调用数与总时延，并分别消融校正和交接。仿真与观测检查通过后，再开展小规模真机验证。

Deliverable: a reproducible comparison and a clear account of where local feedback helps or fails, with an implementation and error analysis that can support a paper.预期交付：可复现的对照评估、局部反馈的收益与失败边界，以及可支撑论文的实现和误差分析。

Position relative to prior work与已有工作的关系

Feedback controller sequences and Riccati synthesis have clear precedents [1]. Action-chunking theory motivates careful attention to stability and exploration data [2], while RTC addresses inference latency and chunk transitions [3]. The proposed contribution is to learn plan-conditioned local dynamics around a frozen VLA, compile feedback at inference time, and test correction and replanning decisions under bounded model validity. Its value must be established against these alternatives.

反馈控制器序列与 Riccati 合成已有明确先例 [1]；动作分块理论提示我们关注稳定性与探索数据 [2]；RTC 则处理推理延迟和动作块衔接 [3]。本提案拟贡献的是：围绕冻结 VLA 学习计划条件化的局部动力学，在推理时编译反馈，并在有限的模型有效范围内检验校正与重规划决策。其价值需要通过与这些已有方案的比较来证明。

  2. Zhang, Pfrommer, Pan, Matni & Simchowitz. Action Chunking and Exploratory Data Collection Yield Exponential Improvements in Behavior Cloning for Continuous Control. 2025.
  3. Black, Galliker & Levine. Real-Time Execution of Action Chunking Flow Policies. NeurIPS 2025.
